# Security Policy

## Supported versions

Only the latest state of the `main` branch is supported.

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities.

Instead, use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability): go to the repository's **Security** tab → **Report a vulnerability**.

You can expect an initial response within a week. Please include reproduction steps and the affected area (desktop shell or shared packages) where possible.
