# Umber 0.2

Image details now accept another prompt using the selected image as the reference. The model, resolution, quality and aspect ratio stay the same. Each edit creates one new gallery item. The version strip connects the family, including edits made from earlier versions. Numbers are assigned when results are saved so concurrent edits cannot receive the same number. Deleting a version does not renumber the others.

The aspect-ratio menu offers **First image** on models with reference-image support. It reads the first attached reference, including its orientation. Matching uses the model's listed shapes. GPT Image 2, GPT Image 2.5 and FLUX.2 also accept custom shapes between 1:3 and 3:1 through Umber's existing pixel-size rules. Those rules round dimensions to the provider's grid. Other shapes are rejected before making a paid request. Models without reference-image support do not offer this option.

This is conservative integration coverage, not a claim that every provider's native API has the same limits. [OpenAI documents custom sizes and fixed legacy sizes](https://developers.openai.com/api/reference/cli/resources/images/methods/generate). [BFL documents flexible FLUX.2 dimensions](https://help.bfl.ai/articles/8916739058-what-aspect-ratios-and-output-dimensions-are-supported). [Google documents input matching and explicit aspect-ratio options](https://ai.google.dev/gemini-api/docs/image-generation). Umber uses explicit catalog shapes for Google and the other fixed-shape integrations in this release.

The Usage button in the navbar shows successful creations, model totals, average rendering time and estimated USD cost for the last 7 days, 30 days or 365 days. The graph switches between cost and creation count. The year view groups days into calendar months. The metadata ledger survives gallery deletion and is cleared by Erase all data. Existing creations are imported without inventing missing costs or durations. Failed requests and charges absent from the catalog estimate are excluded, so this is not a provider invoice.

Gallery tiles reveal cost, rendering time and date in a small glass pill on hover or keyboard focus. Edited images also carry a version label.

Validation covers ratio constraints, edit settings and references, usage boundaries, missing metadata, deletion retention and concurrent version numbering. Browser checks used isolated fixtures and a mocked OpenAI response. No paid generations or release publication were performed.
